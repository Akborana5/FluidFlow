# FluidFlow - AI-Powered React Page Builder

Transform wireframes and sketches into functional React applications using AI.

## 🚀 Features

- **Sketch to Code**: Upload wireframes/mockups and generate complete React applications
- **Multi-AI Support**: Works with Gemini, OpenAI, Claude, MiniMax, ZAI, and more
- **Live Preview**: Real-time preview with device simulation (desktop, tablet, mobile)
- **Code Editor**: Monaco-powered editor with syntax highlighting and split view
- **GitHub Integration**: Push directly to GitHub repositories
- **Version Control**: Built-in Git with commit history and WIP persistence
- **AI-Powered Features**: Auto-fix, accessibility audit, responsiveness fix, and more

## 🎯 Usage

1. **Upload** a wireframe or mockup image
2. **Add Context** or brand logo (optional)
3. **Generate** - Click to create your React app
4. **Iterate** - Use chat or quick edit to refine
5. **Export** - Download as ZIP or push to GitHub

## ⚙️ Configuration

To use this Space, you'll need to configure at least one AI provider API key in the Settings panel (click the gear icon) once the application loads.

Alternatively, you can set environment variables when deploying your own instance:
- `GEMINI_API_KEY` - Google Gemini API key
- `OPENAI_API_KEY` - OpenAI API key
- `ANTHROPIC_API_KEY` - Anthropic API key
- `OPENROUTER_API_KEY` - OpenRouter API key
- `ZAI_API_KEY` - ZAI API key
- `MINIMAX_API_KEY` - MiniMax API key
